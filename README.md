# 🎬 Movies Analytics Dashboard

An interactive data analytics dashboard built on the TMDB Movies Dataset to explore trends, ratings, revenues, and genres.

## 🔍 What This Project Does
- Analyzes 5000+ movies from TMDB dataset
- Explores genre trends, ratings, and revenues
- Builds an interactive dashboard with filters

## 🛠️ Tech Stack
- **Python, Pandas, NumPy**
- **Matplotlib, Seaborn, Plotly**
- **Streamlit** (for dashboard)

## 📌 Dataset
